# Why this project

This project is primarily for learning about Swing and Spring. This combination has some unique challenges.

It is a learning experience, and that means, the development will not always be straight. Some components will be to complicated, and some basic features will come later.

# The goal

The goal is an image viewer with support for AI generated images from CivitAI. The metadata and the generation prompt for an image will be displayed, 
I have some ideas for a tagging system, and CivitAI has a Rest API, which I want to use.
